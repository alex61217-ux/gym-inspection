雲端同步設定與權限修復 (Firebase)

⚠️ 偵測到權限不足或匿名登入未啟用

系統已自動保留本機儲存功能，不影響現場勾選。若需啟用雲端同步，請至 Firebase Console 確認：

  1. Authentication → Sign-in method：啟用 Anonymous（匿名） 登入。
  2. Firestore Database → Rules：發佈允許已驗證連線讀寫的規則：
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
